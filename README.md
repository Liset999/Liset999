### 核心项目

- **[ZenDesktop](https://github.com/Liset999/ZenDesktop)** — 基于原生 C++ 与 Windhawk 机制的高性能 Windows 桌面增强工具（500+ Stars）。
- **[Sentinel](https://github.com/Liset999/Sentinel)** — 基于 Linux `/proc` 文件系统的轻量级系统指标采集与可观测框架，兼容 Prometheus 规范。
- **[server-monitor-app](https://github.com/Liset999/server-monitor-app)** — 移动端服务器监控客户端，支持实时指标汇总与节点连通性巡检。
